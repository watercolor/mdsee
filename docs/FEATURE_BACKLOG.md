# mdcli 待补功能清单

更新日期：2026-11-14。

本清单记录与 mdterm、mdedit、Glow 等项目对比后提出的功能候选，供确定后续开发顺序。已完成项目在备注中标记，其余项目待排期，按功能分组展示。

在“优先顺序”栏填写 1、2、3 等数字；暂时不做的项目填“暂缓”。可在备注中调整范围、拆分需求或说明使用场景。编号保持不变，方便后续引用。

## 当前已有能力

- 多文件 Markdown 编辑，支持中文、多行粘贴、撤销和重做。
- 双列、仅编辑、仅预览布局，以及双向关联滚动。
- Vim 核心操作、源码行号定位和未保存退出提示。
- 标题、列表、表格、任务列表、链接及预览代码块语法高亮。
- Unicode 文本公式排版。
- 本地 PNG、JPEG、GIF 首帧预览，支持 Kitty Unicode 图片占位符和彩色半块字符。
- HTTP/HTTPS 网络图片异步下载、会话缓存、超时与大小限制，以及加载和失败提示。
- `--images auto|kitty|blocks|off`；默认自动识别支持的终端，包括 iTerm2 3.7.3 及以上正式版。
- 原子保存、保存前外部修改检测，以及 `--print` 文字输出。

任务列表目前可显示，尚不能在预览中直接勾选。链接的终端超链接能力也不等同于应用内的跨文档导航。

## 排期时需要考虑的现有边界

- 文本文件最大 2 MiB；撤销历史最多 100 次变更、约 8 MiB 快照。
- 复杂 Emoji 和组合字符的光标移动仍按 Unicode 码点处理。
- 文档或窗口变化时重建预览，本地图片在单次渲染任务内复用，网络图片缓存跨渲染任务保留到会话结束。
- iTerm2 3.7.7 的 Kitty 原图显示与自动识别已经用户实测确认；Kitty、Ghostty 等其他终端，以及 Linux 和 Windows 的原生交互仍待验证。
- 以上边界可单独转为需求，暂不自动计入功能排期。
